# 要件定義書

## 1.どんなゲーム？

敵を倒してお金を稼ぐゲーム

## 2.勝ち負け条件

勝利条件：お金を１００００円貯めてクリアチケットを買うとクリア

敗北条件：敵にＨＰを０にされる

## 3.作らないもの

- BGMはつくらない
- ステージは一つだけ
- セーブ機能はつくらない

## 4.これができたら完成

- プレイヤーと敵のHPが表示される
- 敵を倒したらお金がもらえる
- １００００円貯めたらクリアになる

## 5.今回私が追加するもの
- ポーション追加
　　回復のポーション
    力のポーション
    弱体化ポーション
    プレイヤーのHPアップポーション
    プレイヤーの防御力アップポーション
    敵を混乱させ、攻撃が当たる確率を1/2にするポーション
- 武器追加
    武器を5個追加する
- 武器効果追加
    炎の剣・・・・・敵に継続ダメージ（1秒に10ダメージ、10回）
    雷鳴の剣・・・・敵に1/10の確率で追加ダメージ（150ダメージ）
    聖剣エターナル・1/5の確率で相手を即死させる
― 武器耐久度
    鉄の剣・・・・・敵に30回攻撃した場合破損、鉄の剣消滅する
    鋼の剣・・・・・敵に100回攻撃した場合破損、鋼の剣消滅する
    炎の剣・・・・・敵に60回攻撃した場合破損、炎の剣消滅する
