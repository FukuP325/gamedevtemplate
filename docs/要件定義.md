# 要件定義書

## 1.どんなゲーム？

敵を倒してお金を稼ぐゲーム

## 2.勝ち負け条件

勝利条件：お金を１００００円貯めてクリアチケットを買うとクリア

敗北条件：敵にＨＰを０にされる

## 3.作らないもの

- BGMはつくらない
- ステージは一つだけ
- セーブ機能はつくらない

## 4.これができたら完成

- プレイヤーと敵のHPが表示される
- 敵を倒したらお金がもらえる
- １００００円貯めたらクリアになる

    力のポーション
